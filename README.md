<h1>SOFTWARE</h1>

- [YASB](https://github.com/amnweb/yasb) —  Customizable Windows status bar that lets me add widgets and personalize my desktop.
- [Zen Browser](https://zen-browser.app/) — Firefox-based browser, highly customizable web browser with a clean, modern interface.
- [Brave Browser](https://brave.com/) — fast and privacy-focused web browser with built-in ad and tracker blocking.
- [Vencord](https://github.com/Vendicated/Vencord) — Discord client modification that adds customization options, themes, and plugins.
- [Spicetify](https://github.com/spicetify) — tool that lets me customize Spotify's appearance and functionality.
- [Visual Studio Code](https://github.com/microsoft/vscode) —  powerful and lightweight code editor for programming and customization.
- [Flow Launcher](https://github.com/flow-launcher/flow.launcher) —  fast application launcher that helps me search for apps, files, and commands.
- [Windhawk](https://github.com/ramensoftware/windhawk) —  Windows customization tool that lets me modify and tweak different parts of the system.
- [Komorebi](https://github.com/lgug2z/komorebi) —  tiling window manager for Windows that automatically organizes and manages windows.
- [AltSnap](https://github.com/RamonUnch/AltSnap) —  lightweight Windows utility that makes moving and resizing windows easier with keyboard and mouse shortcuts.
